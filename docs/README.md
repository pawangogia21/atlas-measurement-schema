# Documentation

Schema design documentation and conventions.

- `conventions.md`: units, coordinate frames, the frame of reference and session binding, the `FrameBundle` contract, optional geometry fields, axis order and uncertainty (sigma, CI95) that the Kits, Ingestion, Processing and the Measurement service agree on.

The algorithm specification (`algorithm-spec.md`) lives at the repository root, next to `vectors/conformance/`, not in this folder. The tolerance function and the association rule are in `../tolerance/README.md`, the client JSON Schemas in `../json-schema/README.md`.
